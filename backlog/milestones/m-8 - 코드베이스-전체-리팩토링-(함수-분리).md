## Description

함수를 최대한 작게 나누는 방향의 전체 리팩토링 요청. 시작 전 확인 필요: 'Extract Function'은 의미 있는 덩어리 단위로 하는 게 표준이고 무조건 잘게 쪼개면 오히려 가독성이 떨어질 수 있어(over-fragmentation), 실제 before/after 예시로 어느 선까지 쪼갤지 사용자 판단을 받아야 함(m-6 세션 중 확립된 원칙, feedback_refactoring_before_after 참고). 기능 추가(m-7) 작업과는 별개로, 완료 후 착수.
