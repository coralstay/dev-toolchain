## Description

현재 언어별 기본 버전(nodejs/pnpm/java/gradle/python/rust/golang)은 저장소 루트 .tool-versions에 하드코딩된 정적 값이 유일한 소스다 (scripts/install/00_select.sh:38 DEFAULT_CONFIG, scripts/lib.sh:373-381 each_tool()이 파싱).

기능 요청: 이 기본값을 각 언어의 upstream 저장소 메타데이터(git tags, GitHub Releases API, 언어별 배포 인덱스 등)에서 동적으로 가져오는 기능. 저장소 메타데이터 외에도 다른 방법(asdf 자체 제공 기능 등)이 여럿 있어 먼저 조사가 필요.

중요한 기존 제약: scripts/install/00_select.sh:282-298 ask_version()의 주석(284-288)이 "asdf list all <plugin>을 phase 0(00_select.sh 실행 시점)에서 쓰지 않는 이유"를 이미 명시하고 있음 — 이 시점엔 asdf/플러그인이 아직 설치 보장이 안 되고, list-all 자체도 네트워크 조회라 느릴 수 있음. 새 기능은 이 제약을 무시하지 말고 반영/우회해야 함.

2026-08-30 Explore agent 조사로 확인: 이 저장소엔 upstream 메타데이터 조회 코드가 전혀 없음 (api.github.com, git ls-remote, asdf list all 등 전수 grep 결과 0건, 유일한 언급은 위 주석에서 "안 쓰기로 한 이유"뿐).

스토리 단위: 조사(spike)와 구현(task)을 하나의 마일스톤 안에서 스토리로 분리 (m-11 다운로드 무결성 검증과 동일 패턴, 저장소 내 마일스톤 단위 일관성 유지).
